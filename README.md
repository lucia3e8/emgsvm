# Subvocal Recognition Colllar
Eventually, a neck-worn sEMG + neck microphone for near-subvocal speech recognition.

Currently, some prototypes

## Layout

```
.
├── adc # tests for a promising 8-channel ADC chip
├── afe # janky, INA128-based analog frontend
├── components # for KiCad
├── datasheets
├── piezo # preamp for a piezo mic
├── scripts # random nonsense
├── spice # analog circuit simulation
```
